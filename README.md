# Godot Gamedev Projects

A collection of small game development projects built with the [Godot Engine](https://godotengine.org/), each living in its own folder. This repo serves as a practice space for learning game dev fundamentals in Godot.

## Projects

| Project | Description |
|---|---|
| [bossfight-codechef](./bossfight-codechef) | A boss-fight style game/mechanic prototype. |
| [top down shooter](./top%20down%20shooter) | A top-down shooter game prototype. |

## Requirements

- [Godot Engine](https://godotengine.org/download) (recommended: latest stable release)

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/dvyuh/godot-gamedev-projects.git
   cd godot-gamedev-projects
   ```
2. Open the Godot Engine.
3. Use **Import** (or **Open**) in the Godot project manager and select the `project.godot` file inside the project folder you want to run (e.g. `bossfight-codechef/` or `top down shooter/`).
4. Press **Run** (F5) in the editor to play.
